1. Почему для денег decimal, а не double?
double иногда ошибается в дробях, для денег это потерянные копейки. decimal считает точно как на бумаге поэтому для денег берут его

2. Что будет, если byte переполнится?
Ошибку не выдаст, а прибавит +1 и начнет счет по новому с 0

3. Чем var отличается от Python? Когда компилятор определяет тип?
var это просто способ не писать тип руками. Компилятор  смотрит на то что было написано первым и фиксирует этот тип

4. Какой тип всегда возвращает Console.ReadLine()?
Всегда строковый тип string

5. Чем int.Parse отличается от int.TryParse?
Если ввести буквы вместо цифр Parse выдаст с ошибкой а TryParse нет, а вернет false.

6. Что значит false из TryParse и что будет в out-переменной?
false значащая что было введено string а не int в переменную запишется 0

7. Пример, когда нужен TryParse, а не Parse.
Если мы запрашиваем возраст пользователя если использовать Parse а пользователь введет букву программа остановиться с TryParse программа напишет ошибку ввода и продолжит работать
